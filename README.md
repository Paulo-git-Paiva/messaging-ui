Desafio técnico frontend desenvolvido com Vue 3, Typescript, Pinia e CSS/SASS

## Funcionalidades

- Sidebar lateral com navegação
- Lista de conversas
- Área principal do chat
- Campo de digitação
- Botão de envio
- Seleção de conversa e exibição dinâmica de mensagens
- Envio de novas mensagens
- Estado "digitando..."
- Scroll customizado na lista de mensagens
- Enter para envio de mensagem
- Shift + Enter para quebra de linha
- Responsividade
- Componentização reutilizável
- Gerenciamento de estado com Pinia

## Comandos para executar o projeto

```bash
npm install
npm run dev
```
